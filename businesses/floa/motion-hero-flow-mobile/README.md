# FLOA hero film (phone)

The phone version of `../motion-hero-flow/`: the same story, the same times and the same words,
recomposed for a tall frame (880x1100, 4:5): bigger cards and type, the cards stacked instead of
side by side. On a phone the picture is about 360 px wide, so every label is drawn to read at
14 px or more there. The site shows this film under 640 px and the wide one above it, and each
visitor downloads only the one they see.

Render it the same way as the wide one (see its README), and write:
`../public/assets/hero-flow-tall.mp4` and `../public/assets/hero-flow-tall-poster.webp`.
