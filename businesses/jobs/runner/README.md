# הסורק של jobs

זה החצי המקומי של האפליקציה: Chrome אמיתי שרץ **על המחשב שלך**, סורק את אתרי הדרושים ושולח קורות חיים. הוא לא חלק מהבילד ולא עולה לאתר.

## הפעלה

```
cd businesses/jobs/runner
npm install
npm run login      # פעם אחת: מתחברים לאתרים בחלון שנפתח, וסוגרים
npm start          # משאיר פתוח בזמן שעובדים באתר
```

ב-`/jobs/` לוחצים "שלח משרות" על סוכן. הסורק מרים את הבקשה, סורק, נותן ציונים וכותב את התוצאות. **סריקה לא שולחת כלום.** משרות נשלחות רק אחרי שמסמנים אותן ולוחצים "שלח את המסומנות".

## מה צריך

- Chrome מותקן במחשב.
- `.env` בשורש הריפו עם `SUPABASE_ACCESS_TOKEN` ו-`SUPABASE_PROJECT_REF` (אותו קובץ ש-`scripts/sql.mjs` משתמש בו).
- אופציונלי: `ANTHROPIC_API_KEY` ב-`.env`. איתו, 15 המשרות הטובות בכל סריקה נקראות שוב על ידי מודל מול כל הפרופיל. בלעדיו הציון נשאר מהסיבוב הראשון (תפקיד, כישורים מהקו"ח, מרחק).

## מה נבדק ומה לא

- **נבדק:** חיפוש ב-AllJobs וב-Drushim, חילוץ משרות, ציונים, מרחק, ושכבת מסד הנתונים.
- **לא נבדק:** ההגשה עצמה (`apply` ב-`sites.mjs`). היא דורשת שאתה מחובר לאתר, ואי אפשר לבדוק אותה בלעדיך. היא כתובה בזהירות: מסמנת "נשלח" רק כשהאתר אומר במפורש שנשלח, ובכל מקרה אחר "דורש הגשה ידנית" עם קישור.
- **LinkedIn:** עדיין לא. הוא דורש התחברות כבר כדי לחפש, וזה החלק הכי שביר והכי מסוכן לחשבון.

## כלים

- `node try.mjs "מפתח/ת Full Stack" "תל אביב" 25`: סריקה וציונים לסוכן מדומה, בלי מסד.
- `node uitest.mjs`, `node uitest2.mjs`: בודקים את מסכי הדשבורד ואת בורר התפקידים עם Supabase מדומה (צריך בילד קודם).

## כשאתר שובר

אתר שמשנה עיצוב שובר את החיפוש שלו, ואין מה לעשות מהצד שלנו. הסריקה ממשיכה לאתר הבא ושומרת בהערה של הריצה מה נכשל. בדיקת בוט (captcha) לא נפתרת בקוד: הסריקה נעצרת באתר הזה.

## מקורות הנתונים

- **תפקידים:** הרשימה של דרושים עצמם (35 תחומים, 639 תפקידים), `public/assets/roles.json`, נוצרת עם `node roles.mjs`. דרושים נסרק לפי קוד התפקיד, לא לפי מילים.
- **ערים:** GeoNames (https://www.geonames.org, רישיון CC BY 4.0), כל יישוב מעל 8,000 תושבים, `public/assets/cities.json`, נוצר עם `node cities-build.mjs IL.txt`.
- AllJobs עדיין נסרק לפי מילות התפקיד, כי לא מצאתי לו רשימת תפקידים ציבורית.
