# חוקי UI של FLOA

הסקיל המלא יושב בספריית ה-UI של הפרויקט, יחד עם האסימונים והרכיבים: **`ui/SKILL.md`** (בשורש הפרויקט, במקביל ל-`apps/`).

לפני כל שינוי שנוגע במראה, וגם לפני בניית אפליקציה או מסך חדש, קוראים את `ui/SKILL.md` כולו (החוקים, המסלול המודרך והאינדקס), ואת הקובץ ב-`ui/docs/` של כל רכיב שנוגעים בו, ופועלים לפיהם. כל חוק חדש נכתב שם, לא כאן. הקובץ הזה רק מפנה אליו, כדי שהסקיל ייטען.
